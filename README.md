### Open source

#### [LatticeLog](https://github.com/lreyesm1999/LatticeLog)

<a href="https://github.com/lreyesm1999/LatticeLog"><img src="https://raw.githubusercontent.com/lreyesm1999/LatticeLog/main/docs/assets/latticelog-hero.png" alt="LatticeLog" width="640"></a>

Typed, local-first structured logging for .NET:

- an open binary log format (`.llog`) with indexed queries;
- a CLI and a web console;
- an MCP server, so coding agents can search your logs and cite the exact events.

It also has SDKs for Python and PHP, a Windows installer, and an MIT license. It is in alpha.

[Five-minute tutorial](https://github.com/lreyesm1999/LatticeLog/blob/main/docs/guides/getting-started.md) ·
[Releases](https://github.com/lreyesm1999/LatticeLog/releases)

#### [Agentic Discipline Kit](https://github.com/lreyesm1999/agentic-discipline-kit)

Engineering controls for AI coding agents. It gives requirements, tests and releases deterministic quality gates and
reproducible evidence, instead of relying on the model's own account. It works with Claude Code, Cursor, Copilot and
other assistants. Install it with `npm` or `pip`. MIT license.
